# oh-my-telegram

Личный бот-пульт для управления своим Telegram-аккаунтом. Бот отвечает
только владельцу (`bot.owner_id`), действия над аккаунтом выполняет
юзербот на Telethon.

## Правила

### 👤 Подключение аккаунта (через бота)

«👤 Аккаунт» → «Подключить» → поделиться контактом → код набирается
цифровой клавиатурой (код в сообщении Telegram аннулирует) → пароль 2FA
одним сообщением, бот удаляет его сразу. Сохраняется только сессия —
зашифрованной (AES-256-GCM, ключ `security.session_key` вне БД). Принимается
только аккаунт с ID = `owner_id`. «Выйти» отзывает сессию в Telegram.

### 🎭 Ротация эмодзи-статуса (нужен Telegram Premium)

- Пул премиум-эмодзи: пришли боту сообщение с ними или ссылку на пак
  `t.me/addemoji/<name>` — добавится весь пак.
- Смена по таймеру: пресеты от 15 мин до 2 дней или свой интервал
  (`90`, `3ч`, `1д`, `1ч30м`).
- Управление как в плеере: ⏮ предыдущий / ⏸ пауза / ⏭ следующий. ⏮ идёт
  назад по истории, ⏭ — сначала вперёд по ней, потом новый случайный.
- 🗑 удалить текущий (сразу ставится другой), 📋 пул с удалением.
- Расписание хранится в БД: рестарт не сбивает время следующей смены.
- Если Telegram отказал (нет Premium, flood wait) — бот напишет один раз
  и повторит попытку позже.

### 💬 Команды в чатах

Работают в любом чате — личка, группы, «Избранное». Исключение — `!mute`
и `!unmute`: только в личке с человеком.

- `!mute 30s` / `10m` / `2h` / `1d` / `1w` / `1mo` (месяц) / `1y` — команда
  превращается в «тише тише 🤫», и все новые сообщения собеседника удаляются
  у обоих, пока не истечёт срок. Можно по-русски: `15м`, `3д`, `1мес`.
- `!unmute` — снять досрочно («ладно, говори 🗣»).
- `!spam 5 текст` — команда удаляется, текст уходит 5 раз (не больше 50).

- `!type текст` — печатная машинка с курсором `▌`.
- `!🌑` (любая фаза луны) — полный лунный цикл от неё же до неё же.
- `!❤️` — пиксельное сердце: рисуется, переливается, радуга → большой ❤️.
- `!typing` / `!voice` / `!round` / `!video` / `!file` / `!photo` /
  `!sticker` `[срок]` — команда удаляется, собеседник видит «печатает…»,
  «записывает голосовое…», «записывает видеосообщение…» и т.д. (по
  умолчанию 30s, максимум 10m).
- `!stop` — остановить анимацию/действие в этом чате. Новая команда в том
  же чате тоже отменяет предыдущую.

Команду с опечаткой бот не трогает — она остаётся обычным сообщением.

## Запуск

```bash
cp config.example.toml config.toml   # токен бота, owner_id, api_id/api_hash
make gen-key                         # → security.session_key
cp .env.example .env
uv sync
make up                              # postgres + приложение
# дальше в боте: /account → «Подключить аккаунт»
```

Команды бота: `/start` или `/menu` — меню, `/emoji` — статус, `/account` —
аккаунт.

⚠️ `security.session_key` + дамп БД = доступ к аккаунту. `config.toml` в
`.gitignore`, не коммить его и не пересылай.
